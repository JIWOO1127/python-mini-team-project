## 기준 폴더

모든 명령은 아래 폴더에서 실행합니다.

```text
C:\Users\한국전파진흥협회\Desktop\DA\For Share\EV_Diag_Final
```

PowerShell 실행 정책 오류를 피하기 위해 `.ps1` 또는 `.cmd` 파일 대신 **Python 직접 명령**을 사용합니다.

## 1. 최초 1회: 가상환경과 라이브러리 설치

PowerShell을 열고 아래 명령을 순서대로 실행합니다.

```powershell
cd "C:\Users\한국전파진흥협회\Desktop\DA\For Share\EV_Diag_Final"

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`py`를 찾을 수 없다는 오류가 나오면 첫 번째 명령만 아래처럼 바꿉니다.

```powershell
python -m venv .venv
```

이 과정은 LightGBM, FastAPI, Tkinter UI 실행에 필요한 라이브러리를 설치합니다.

## 2. API 키 확인

프로젝트 루트의 `.env` 파일을 열어 아래 값을 입력합니다. 실제 키 값은 팀 내부에서만 공유합니다.

```dotenv
KAKAO_REST_API_KEY=발급받은_카카오_REST_API_키
KMA_SERVICE_KEY=발급받은_기상청_서비스_키
BACKEND_BASE_URL=http://127.0.0.1:8000
```

`.env` 파일이 없다면 아래 명령으로 만들 수 있습니다.

```powershell
Copy-Item .env.example .env
```

## 3. 서버 실행

첫 번째 PowerShell 창에서 아래 명령을 실행합니다.

```powershell
cd "C:\Users\한국전파진흥협회\Desktop\DA\For Share\EV_Diag_Final"

.\.venv\Scripts\python.exe -m uvicorn src.backend.main:app --host 127.0.0.1 --port 8000
```

아래 문구가 보이면 서버가 정상입니다. 이 PowerShell 창은 **종료하지 않고 유지**합니다.

```text
Uvicorn running on http://127.0.0.1:8000
```

브라우저에서 다음 주소를 열어 서버 상태를 확인할 수 있습니다.

```text
http://127.0.0.1:8000/health
```

응답에서 아래 내용을 확인합니다.

```json
{
  "status": "ok",
  "active_model": "lightgbm-ver2"
}
```

## 4. Tkinter 앱 실행

**새 PowerShell 창**을 열고 아래 명령을 실행합니다.

```powershell
cd "C:\Users\한국전파진흥협회\Desktop\DA\For Share\EV_Diag_Final"

.\.venv\Scripts\python.exe -m src.ui
```

앱이 열리면 차량 ID와 주소를 입력해 분석하고, 두 번째 화면에서 충전소와 서비스센터를 검색합니다.

## 5. 데이터 또는 모델을 바꾼 뒤 실행하는 방법

아래 파일을 바꾼 경우 서버는 이전 내용을 메모리에 유지하므로 **서버 재시작이 필수**입니다.

- `data\test\lightgbm-ver2\vehicles.csv`
- `data\test\default\vehicles.csv` (제조사·모델·배터리 표시용 메타데이터)
- `models\lightgbm-ver2\lgbm_battery_model.pkl`
- `models\model_manifest.json`
- `data\test\lightgbm-ver2\feature_profile.json`

재시작 순서:

1. 서버 창에서 `Ctrl + C`로 서버를 종료합니다.
2. 필요한 파일을 교체합니다.
3. 3단계의 서버 실행 명령으로 서버를 다시 시작합니다.
4. 이미 열려 있던 Tkinter 창을 닫습니다.
5. 4단계의 Tkinter 실행 명령으로 앱을 다시 엽니다.

## 6. 문제 해결

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `No module named 'src'` | 프로젝트 폴더 밖에서 서버를 실행함 | `EV_Diag_Final` 폴더로 이동한 뒤 3단계 명령 실행 |
| `.venv` 또는 `python.exe`를 찾지 못함 | 1단계 미실행 | 1단계의 가상환경 생성·라이브러리 설치 실행 |
| `lightgbm` 모듈이 없다는 오류 | LightGBM 설치 전 또는 이전 가상환경 사용 | `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` 실행 |
| `ImportError` 또는 모델 로드 경고 | 라이브러리 버전이 이전 상태 | 위 `pip install -r requirements.txt` 실행 후 서버 재시작 |
| `WinError 10048`, 포트 8000 사용 중 | 이전 서버가 아직 실행 중 | 이전 서버 창에서 `Ctrl + C` 후 다시 실행 |
| `KAKAO_REST_API_KEY` 오류 | `.env`에 키가 없거나 잘못 입력됨 | 루트 `.env`의 Kakao 키 확인 후 서버 재시작 |
| 차량 ID는 조회되지만 제조사·모델·배터리가 비어 있음 | 메타데이터 CSV가 없거나 ID가 일치하지 않음 | `data\test\default\vehicles.csv`의 `vehicle_id`, `vehicle_brand`, `vehicle_model`, `battery_chemistry` 열 확인 |
| 폭스바겐 서비스센터가 비어 있음 | 공식 목록 수집 실패 또는 기존 서버 사용 | 서버 재시작 후 재검색. 공식 목록 실패 시 카카오맵 크롤러 fallback 사용 |
